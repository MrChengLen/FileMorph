### Added — a link to a public status page, set per deployment

A new setting, `STATUS_PAGE_URL`, adds a "Status page" link to the footer's
Product group. It is empty by default, so a self-hosted instance shows no
link unless its operator runs a status page. filemorph.io points it at its
status page on GitHub Pages, which checks the website and the API about
every five minutes and keeps the history. The privacy policy describes that
page in a new section 4a (GitHub as host, no cookies or tracking, a copy of
the public status data in the browser's localStorage) and names it where it
lists the processing based on legitimate interest.

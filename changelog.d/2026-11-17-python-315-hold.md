### Changed — Dependabot holds the image on Python 3.14 until 3.15 can be built

Dependabot no longer proposes moving the image to Python 3.15 (#332). The
image cannot be built on 3.15 yet: pillow-avif-plugin, which FileMorph's AVIF
support needs, publishes no wheel for it. Python 3.14 gets bug fixes until
October 2027, and new builds of `python:3.14-slim`, which bring Debian's
security fixes and Python's 3.14.x releases, keep coming. The hold is to be
looked at again on 2027-04-01. The move to 3.15 changes the Dockerfile, the
workflows, the browser test job's image and the lockfiles in one pull request
and drops the entry in `.github/dependabot.yml`; a new test fails if the entry
outlives that move.
